# 1622·攻剿红夷·镇海志（换皮版）

本版本以原《嘉庆君游台湾：御前争霸》V34 的玩法、AI、回合、牌组数量和胜利判定为底层，进行纯视觉与文案换皮。

## 最终牌面
- 行动牌：探海、巡防
- 地牌：鸿山石壁、浯屿水寨、圭屿海口、澎湖风柜尾
- 计策牌：封港戒严、东风火攻、调营换防
- 军令牌：徐都督令、赵游击令
- 镇海战备：出征将领、水师战船、防海方略、红夷大炮

## 地图关系
- 上：鸿山石壁 → 出征将领
- 左：浯屿水寨 → 水师战船
- 中：中左所军门（起点，不是地牌）
- 右：圭屿海口 → 防海方略
- 下：澎湖风柜尾 → 红夷大炮

## 规则
核心规则与原版保持一致：三人局、70张牌、巡防移动、探海取得对应镇海战备、五张特殊牌效果不变、集齐四种不同镇海战备立即胜利。

## 运行
使用静态网页服务器打开 `index.html`。若部署到 GitHub Pages，可作为独立目录发布，避免覆盖旧版。
